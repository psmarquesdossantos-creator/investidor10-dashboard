# Fases 6-10 — Roadmap de Continuação do Investidor10 Dashboard
> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (Native) — plano para execução inline no dashboard vanilla JS.
> **Meta:** levar o dashboard de protótipo funcional → produto verificável com testes, hardening, CI e deploy.
> **Stack:** HTML/CSS/JS vanilla, Chart.js CDN, localStorage, python -m http.server, Playwright, axe-core, GitHub Actions.
> **Spec:** SKILLS_PLAYBOOK.md + MODEL_SELECTION_GUIDE.md + aprendizados de governança (anexos anteriores).

## Global Constraints
- pt-BR em toda a UI e comunicação.
- Vanilla JS, zero build, funciona via file:// ou python -m http.server.
- UNKNOWN ≠ ZERO; PARTIAL ≠ COMPLETE; STALE ≠ FRESH; ENGINE ≠ DATA_READY.
- Nunca inventar preço, histórico, benchmark, dividendo, rentabilidade.
- Pipeline importação: preview obrigatório, writes=0 antes de confirmar.
- Acessibilidade: axe critical=0, touch targets ≥44px, focus-visible.
- Toda tarefa inicia com skill_view(superpowers correspondente).

## Review Focus
1. Import de JSON com campo ausente (qty=null) → deve marcar UNKNOWN, não 0.
2. XIRR com só compras → deve mostrar PARTIAL "apenas compras", não número falso.
3. localStorage cheio (QuotaExceeded) → import deve falhar com erro claro, não crash silencioso.
4. TWR com 1 snapshot → TRACKING_STARTED com mensagem, não NaN.
5. Provento duplicado (mesma data/ticker/valor) importado 2x → dedup deve bloquear o segundo.
